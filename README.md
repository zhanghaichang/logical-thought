## 🧩 逻辑思维的核心方法论

```
         ┌──────────────┐
         │  💡 思维动机   │ ← 为什么要思考？
         └──────┬───────┘
                ▼
         ┌──────────────┐
         │  🗺️ 思维脉络   │ ← 如何清晰思考？
         └──────┬───────┘
                ▼
         ┌──────────────┐
         │  🔧 思维方法   │ ← 具体怎么做？
         └──────────────┘
```

## 🎯 每种方法的核心价值

| 方法 | 核心能力 | 适用场景 |
|------|---------|---------|
| 🔘 **假设法** | 先假设，再验证 | 信息不全时的推理 |
| 🔢 **计算法** | 数学思维，精确定量 | 数据关系题 |
| 🚫 **排除法** | 排除不可能，保留可能 | 多条件筛选题 |
| 🔬 **分析法** | 深入拆解，层层剖析 | 复杂逻辑题 |
| 👁️ **观察法** | 发现规律，找到线索 | 图形规律题 |
